##  Описание

**SberBusiness** — фоновая утилита для автоматизации получения банковских выписок из СберБизнес.  
Программа подключается к почтовому ящику по IMAP, отслеживает входящие письма с отчётами, скачивает Excel-файлы по временным ссылкам и сохраняет их в локальную директорию. Работает в режиме системного демона с визуальным индикатором статуса в трее Windows.

Создана для полного устранения ручной рутины, минимизации человеческого фактора и обеспечения бесперебойной работы даже при выключенном компьютере в выходные дни.

## ✨ Ключевые возможности

| Возможность | Описание |
|-------------|----------|
|  **Автозапуск** | Запускается автоматически при входе пользователя в систему |

| 🔐 **Безопасный конфиг** | Изолированный `.env`, поддержка паролей приложений, `npm audit` |

## 🛠 Требования

- **ОС:** Windows 10 / 11 (64-bit)
- **Среда:** Node.js `v24.15.0` или новее
- **Сеть:** Стабильный доступ к интернету и IMAP-серверу
- **Права:** Администратор только на этапе установки (`setup.bat`)

> ⚠️ Для почтовых сервисов (Gmail, Yandex, Mail.ru) необходимо использовать **пароль приложения**, а не основной пароль от аккаунта.

## 🚀 Установка и запуск

1. **Скачайте репозиторий** или распакуйте архив в удобную директорию (например, `C:\SberBusiness`).
2. **Запустите установщик** от имени администратора:
   ```bat
   setup.bat
   ```
3. **Следуйте инструкциям** в консоли:
   - Установятся зависимости (`npm ci`)
   - Проверится безопасность пакетов (`npm audit`)
   - Создастся шаблон `.env` (откроется в Блокноте)
4. **Заполните `.env`** своими данными и сохраните файл.
5. **Готово.** Утилита появится в системном трее при следующем входе в систему или сразу после выбора `Y` в установщике.

## ⚙️ Конфигурация

Файл `.env` (лежит в корне проекта):

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `IMAP_HOST` | `imap.gmail.com` | Хост IMAP-сервера |
| `IMAP_PORT` | `993` | Порт (SSL/TLS) |
| `IMAP_USER` | — | Email-адрес ящика |
| `IMAP_PASS` | — | Пароль приложения |
| `DOWNLOAD_DIR` | `C:\SberStatements` | Путь для сохранения выписок |
| `SUCCESS_TIME` | `10:00` | Время ежедневной проверки |
| `RETRY_HOURS` | `3` | Интервал повтора при сетевых ошибках |

> 📌 Все изменения в `.env` применяются после перезапуска утилиты (правый клик по иконке → **Выход** → повторный запуск через ярлык в автозагрузке).

## 📊 Как это работает

### Цикл жизни процесса
1. **Запуск** → инициализация IMAP-соединения, загрузка конфига.
2. **Поиск** → `SEARCH UNSEEN SUBJECT "Выписка по счету"`.
3. **Парсинг** → извлечение ссылки и даты периода из HTML.
4. **Валидация** → `HEAD`-запрос к ссылке. Если `403/404/410` → ссылка истекла, письмо помечается прочитанным.
5. **Скачивание** → стриминг тела ответа → проверка Magic Bytes → сохранение с детерминированным именем (`Sber_Statement_YYYY-MM-DD.xlsx`).
6. **Статус** → обновление иконки в трее, запись в `logs/status.json`, планирование следующего запуска.

### Поведение при сбоях
| Ситуация | Действие утилиты |
|----------|------------------|
| Нет интернета / таймаут IMAP | Письмо остаётся `UNSEEN`, ретрай через `RETRY_HOURS`, красная иконка |
| Ссылка истекла (>22 часов) | Письмо помечается `SEEN`, лог фиксирует проблему, MessageBox-уведомление |
| Файл уже существует | Пропуск скачивания, экономия трафика и времени |
| Повреждённый ответ (не XLSX) | Файл удаляется, ошибка логируется, ретрай не запускается |

## 🔒 Безопасность

- ✅ **Изоляция секретов:** Пароли хранятся только в `.env`, не попадают в логи и не передаются третьим сторонам.
- ✅ **Валидация контента:** Проверка сигнатуры ZIP/XLSX перед записью на диск защищает от подмены HTML-ошибками или вредоносными скриптами.
- ✅ **Аудит зависимостей:** `setup.bat` автоматически запускает `npm audit` и блокирует установку при критических уязвимостях.
- ✅ **Безопасные заголовки:** Имитация стандартного `User-Agent` браузера снижает риск блокировки со стороны почтовых фильтров.
- ✅ **Минимальные привилегии:** Утилита работает в контексте текущего пользователя, не требует системных служб или реестра.

## 🆘 Диагностика

| Проблема | Решение |
|----------|---------|
| Иконка не появляется в трее | Проверьте диспетчер задач (`node.exe`). Запустите `setup.bat` заново. |
| Ошибка `IMAP AUTH failed` | Убедитесь, что используется **пароль приложения**, а не основной. Проверьте `IMAP_HOST`. |
| Файлы не скачиваются | Откройте `logs/sber.log`. Ищите строки с `[ERROR]`. Проверьте срок жизни ссылки в письме. |
| Требуется ручной запуск | Дважды кликните по ярлыку `SberBusiness` в меню Пуск или папке `Startup`. |
| Логи переполняются | Файл `sber.log` можно безопасно очистить или удалить — утилита создаст новый. |

**Быстрая проверка статуса:**
```bat
status.bat
```
Выводит последние события и список сохранённых выписок.
