## Описание

**SberBusiness** — фоновая утилита для автоматизации получения банковских выписок из СберБизнес.  
Программа подключается к почтовому ящику по IMAP, отслеживает входящие письма с отчётами, скачивает Excel-файлы по временным ссылкам и сохраняет их в локальную директорию. Работает в режиме системного демона с визуальным индикатором статуса в трее Windows.

## Ключевые возможности

| Возможность | Описание |
|-------------|----------|
| **Автозапуск** | Запускается автоматически при входе пользователя в систему |
| **Гибкое расписание** | Ежедневная проверка в заданное время + автоматический ретрай при ошибках |
| 🟢🔴⚪ **Трей-индикатор** | Визуальный статус: ожидание / успех / ошибка |
| 🛡️ **Валидация файлов** | Проверка ZIP/XLSX-структуры перед сохранением на диск |
| 📩 **Парсинг писем** | Извлечение ссылок и дат периода из HTML/MIME-писем через `cheerio` |
| 🔔 **Уведомления** | MessageBox-уведомления при проблемах или истёкших ссылках |
| 📜 **Логирование** | Логи в `logs/sber.log` + JSON-статус в `logs/status.json` |
| 🔐 **Безопасная конфигурация** | Секреты в `.env`, конфигурация в `config.json`, `.env.example` без реальных паролей |

## Требования

- **ОС:** Windows 10 / 11 (64-bit)
- **Среда:** Node.js `v24` или новее
- **Сеть:** доступ к интернету и IMAP-серверу
- **Права:** администратор только на этапе установки (`setup.bat`)

> Для Gmail/Yandex/Mail.ru нужен **пароль приложения**, не основной пароль от аккаунта.

## Установка и запуск

1. Скачайте репозиторий или распакуйте архив в удобную директорию, например `C:\SberBusiness`.
2. Откройте `config.json` и настройте IMAP, папку поиска, каталог выписок, расписание и параметры tray.
3. Запустите установщик от имени администратора:

   ```bat
   setup.bat
   ```

4. Установщик выполнит:
   - `npm ci`
   - `npm run check`
   - `npm test`
   - `npm audit --omit=dev --audit-level=moderate`
   - создаст `.env` из `.env.example`, если `.env` ещё нет
   - добавит ярлык в автозагрузку Windows

5. Заполните `.env` своими данными.
6. Готово. Утилита появится в системном трее при следующем входе в систему или сразу после выбора `Y` в установщике.

## Конфигурация

Основная конфигурация хранится в `config.json`. Секреты остаются в `.env` и подтягиваются по именам переменных.

### `config.json`

| Раздел | Поле | По умолчанию | Описание |
|--------|------|--------------|----------|
| `imap` | `host` | `imap.gmail.com` | Хост IMAP-сервера |
| `imap` | `port` | `993` | Порт |
| `imap` | `secure` | `true` | SSL/TLS |
| `imap.auth` | `userEnv` | `IMAP_USER` | Имя переменной пользователя |
| `imap.auth` | `passEnv` | `IMAP_PASS` | Имя переменной пароля |
| `mailbox` | — | `INBOX` | IMAP-папка для поиска |
| `search.subject` | — | `Выписка по счету` | SUBJECT-фильтр для писем |
| `downloadDir` | — | `C:\SberStatements` | Каталог для Excel-выписок |
| `successTime` | — | `10:00` | Время ежедневной проверки |
| `retryHours` | — | `3` | Интервал повтора при сетевых ошибках |
| `download` | `headTimeoutMs` | `10000` | Таймаут HEAD-проверки ссылки |
| `download` | `timeoutMs` | `30000` | Таймаут скачивания файла |
| `tray` | `enabled` | `true` | Включить tray |
| `tray` | `title` | `SberBusiness` | Заголовок tray-меню |

### `.env`

| Переменная | Описание |
|------------|----------|
| `IMAP_HOST` | Хост IMAP-сервера |
| `IMAP_PORT` | Порт |
| `IMAP_USER` | Email-адрес ящика |
| `IMAP_PASS` | Пароль приложения |
| `IMAP_MAILBOX` | Перезаписывает `mailbox`, если задано |
| `SEARCH_SUBJECT` | Перезаписывает `search.subject`, если задано |
| `DOWNLOAD_DIR` | Перезаписывает `downloadDir`, если задано |
| `SUCCESS_TIME` | Перезаписывает время ежедневной проверки |
| `RETRY_HOURS` | Перезаписывает интервал ретрая |
| `TRAY_ENABLED` | `true`/`false` для включения tray |

> Все изменения в `.env` и `config.json` применяются после перезапуска утилиты: правый клик по иконке → **Выход** → повторный запуск.

## Как это работает

1. **Запуск** → загрузка `config.json` + `.env`.
2. **Поиск** → `SEARCH UNSEEN SUBJECT "<search.subject>"`.
3. **Парсинг** → извлечение ссылки и даты периода из HTML/MIME-письма.
4. **Проверка ссылки** → `HEAD`. Если `403/404/410`, письмо помечается прочитанным.
5. **Скачивание** → временный файл → проверка ZIP/XLSX-структуры → атомарный `rename`.
6. **Статус** → обновление tray, запись `logs/status.json`, планирование следующего запуска.

### Поведение при сбоях

| Ситуация | Действие |
|----------|----------|
| Нет интернета / таймаут IMAP | Письмо остаётся `UNSEEN`, ретрай через `retryHours`, красная иконка |
| Ссылка истекла | Письмо помечается `SEEN`, лог фиксирует проблему, MessageBox-уведомление |
| Файл уже существует | Пропуск скачивания |
| Повреждённый ответ | Временный файл удаляется, ошибка логируется |

## Безопасность

- Секреты хранятся только в `.env`; `.env.example` не содержит реальных паролей.
- Пароли не пишутся в логи и не попадают в отчёты.
- В Git не должны попадать `.env`, `config.local.json`, временные `.xlsx`.
- Проверка ZIP/XLSX перед записью защищает от сохранения HTML-ошибок вместо файла.
- Для GitHub Actions есть CI: syntax check, unit tests и `npm audit`.

## Диагностика

| Проблема | Решение |
|----------|---------|
| Иконка не появляется в трее | Проверьте диспетчер задач (`node.exe`). Запустите `setup.bat` заново. |
| Ошибка `IMAP AUTH failed` | Проверьте пароль приложения и `IMAP_HOST`. |
| Файлы не скачиваются | Откройте `logs/sber.log`, найдите `[ERROR]`. Проверьте срок жизни ссылки в письме. |
| Требуется ручной запуск | Дважды кликните по ярлыку `SberBusiness` в меню Пуск или папке `Startup`. |
| Логи переполняются | `sber.log` можно безопасно очистить или удалить — утилита создаст новый. |

Быстрая проверка статуса:

```bat
status.bat
```
